# Module and authority map

`prompts.py` owns representation identity, tone and instruction/data boundaries. `context.py` allocates whole evidence/history/tool objects and output reserve with an injectable size counter; character counts are never called model tokens. `twin.py` retains deterministic approved-section retrieval and legacy contact API for compatibility. `tools.py` and `storage.py` own the new typed/idempotent persisted action path; `notifications.py` isolates local versus explicitly configured external effects. `status.py` describes visible action states. `service.py` composes real outcomes and request limits. `config.py` reads settings only when explicitly called. `app.py` imports Gradio only in its factory and delegates actions to the service. `agents_adapter.py` imports provider SDK only inside explicit factories/runs, with no write tools granted to the answering model. `pdf_ingest.py` extracts source text and provenance without granting approval. `evaluate.py` runs the versioned behavioural cases and exports actual failures.

All modules must be safe to import without network requests, database writes, environment dumps or UI launches. The project-local pyproject supplies CLI entry points and packaged synthetic data. Legacy public methods are preserved for existing exercises; the UI uses the typed ToolsService path with stable action IDs.

Fresh schema/state and import parity are author-written test requirements in `tests/test_stage05_semantic_repairs_*.py`; only central guarded QA may claim their observed results. Tool success is a receipt, source approval is an owner decision, generated-answer quality is separately evaluated, and none of these substitutes for the others.
