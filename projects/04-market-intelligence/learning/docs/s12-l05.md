# Controlled external research

The original PDF requires agents to access external information. `FactSearch` only searches the fictional retailer pack and does **not** fulfill that requirement. The new `external_research.py` supplies a real HTTPS document-research adapter and a separate two-agent CrewAI research workflow.

The fixed collection contains official CrewAI tools, tasks and memory pages. This is search **within an approved external document collection**, not a general web search engine. It teaches source access, normalization and review without presenting real framework documentation as evidence for fictional retailer metrics.

`ResearchQuery` validates a nonblank query and integer result count. `ExternalResearch` validates exact source IDs, HTTPS host/port, maximum three requests, eight-second request timeout, bounded body length/content type and UTF-8. It rejects redirects and disables inherited proxy routing. Each attempt is counted before opening the connection. A failed request remains held in that instance and is never automatically retried. Successful documents are cached so a changed query can reuse the same retrieved bytes.

Results contain source ID, URL, actual retrieval timestamp, body SHA256 and an excerpt. `published_at=null` means publication date is unknown; retrieval date must never be described as publication date. Embedded script/style text is omitted, but remaining page text is still untrusted evidence rather than instructions.

After central QA has approved the new adapter, a bounded direct observation can use:

```sh
PYTHONPATH=src python -m academy_market_debate.research_main \
  --observe-http --source crewai-tools --query 'custom tool' --output actual-http-01.json
```

For the agent-tool demonstration, use `--run-crew --model PROVIDER/MODEL` instead under a separately approved provider budget/governor. Only the researcher gets the external tool; the reviewer receives gathered context and returns structured citations. `run_research` checks each reported quote against excerpts actually retrieved during that run. A model citation without a retrieved matching URL/quote is rejected. The fictional debate crew and its four source facts are unchanged.
