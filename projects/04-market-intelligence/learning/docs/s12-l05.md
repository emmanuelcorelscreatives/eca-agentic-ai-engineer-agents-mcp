# Controlled research

FactSearch normalizes results to source/id/text and searches a fixed fictional source. It intentionally does not claim internet search. To add web research later, implement a separate allowlisted provider, source URLs/dates, size limits and a new reviewed budget.

Implementation: `src/academy_market_debate/core.py`.

Observation status: offline checks may be run without credentials. SDK/provider/CLI/real memory runs are separately unexecuted unless accompanied by their own actual receipt.
