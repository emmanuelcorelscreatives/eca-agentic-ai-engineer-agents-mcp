# Controlled external research

This lesson distinguishes external information from local fixtures. `FactSearch` only searches the fictional retailer pack and is **not** external research. `external_research.py` supplies a bounded HTTPS document-research adapter and a separate two-agent CrewAI research workflow.

The fixed collection contains official CrewAI tools, tasks and memory pages. This is search **within an approved external document collection**, not a general web search engine. It teaches source access, normalization and review without presenting real framework documentation as evidence for fictional retailer metrics.

`ResearchQuery` validates a nonblank query and integer result count. `ExternalResearch` validates exact source IDs, HTTPS host/port, maximum three requests, eight-second request timeout, bounded body length/content type and UTF-8. It rejects redirects and disables inherited proxy routing. Each attempt is counted before opening the connection. A failed request remains held in that instance and is never automatically retried. Successful documents are cached so a changed query can reuse the same retrieved bytes.

Results contain source ID, URL, actual retrieval timestamp, body SHA256 and an excerpt. `published_at=null` means publication date is unknown; retrieval date must never be described as publication date. Embedded script/style text is omitted, but remaining page text is still untrusted evidence rather than instructions.

From `projects/04-market-intelligence/learning`, first run the offline validation commands in [runtime checks](runtime-evidence.md). If you choose to access the configured public source, a bounded direct HTTP observation uses no model:

```sh
PYTHONPATH=src python3 -m academy_market_debate.research_main \
  --observe-http --source crewai-tools --query 'custom tool' --output actual-http-01.json
```

For the optional paid agent-tool demonstration, complete [uv setup](s11-l03.md), configure credentials privately and choose an authorized model and finite budget:

```sh
PYTHONPATH=src uv run --frozen --extra crewai python -m academy_market_debate.research_main \
  --run-crew --model PROVIDER/MODEL --source crewai-tools --query 'custom tool' --output actual-crew-01.json
```

Only the researcher gets the external tool; the reviewer receives gathered context and returns structured citations. `run_research` checks each reported quote against excerpts actually retrieved during that run. A model citation without a retrieved matching URL/quote is rejected. The fictional debate crew and its four source facts are unchanged.

No successful HTTP or model result is supplied by this guide. Keep transport-test inputs separate from real retrieved documents and provider outputs; retain actual failures and unknown outcomes without automatically retrying them.
