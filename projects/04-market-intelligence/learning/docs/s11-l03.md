# Install with uv

Use a disposable Python 3.11-3.13 environment. From learning/: uv python install 3.12; uv venv --python 3.12; uv sync --frozen --extra crewai. The committed lock was actually resolved with uv 0.13.8 and installed successfully into a fresh environment; CrewAI 1.15.40 and Pydantic 2.12.5 were observed. Use `uv lock` only when intentionally updating dependencies.

Implementation: `src/academy_market_debate/main.py`.

Observation status: offline checks may be run without credentials. SDK/provider/CLI/real memory runs are separately unexecuted unless accompanied by their own actual receipt.
