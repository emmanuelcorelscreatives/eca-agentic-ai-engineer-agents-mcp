# Install with uv

The offline practical needs only Python 3.11+ and `PYTHONPATH=src`; CrewAI is optional. For SDK exercises, first [install uv](https://docs.astral.sh/uv/getting-started/installation/) and check `uv --version`. Use a dedicated Python 3.11–3.13 environment. From the repository root:

```sh
cd projects/04-market-intelligence/learning
uv python install 3.12
uv venv --python 3.12
uv sync --frozen --extra crewai
uv run --frozen --extra crewai python -c "import sys, importlib.metadata; print(sys.version); print(importlib.metadata.version('crewai'))"
```

`uv run` selects this package's environment; `uv sync` alone does not activate it in your shell. Keep subsequent SDK commands under `uv run --frozen --extra crewai`, rather than using another environment's `python`. Use `uv lock` only when intentionally updating dependencies. Historical version observations are listed in [runtime checks](runtime-evidence.md); record your actual versions rather than assuming they match.
