# Entry point

Run from `projects/04-market-intelligence/learning`. Offline inspection needs no SDK, account or provider call:

```sh
PYTHONPATH=src python3 -m academy_market_debate.main --facts fixtures/retailer-facts.json
```

For an optional paid debate, complete [uv setup](s11-l03.md), configure credentials privately and choose an authorized model and finite budget. Select that environment explicitly:

```sh
PYTHONPATH=src uv run --frozen --extra crewai python -m academy_market_debate.main \
  --facts fixtures/retailer-facts.json --run-live --model PROVIDER/MODEL --output new-run.json
```

These are POSIX shell examples; PowerShell users set `$env:PYTHONPATH = "src"` before the command instead of using a prefix assignment. `--flow` selects the SDK Flow wrapper and `--process hierarchical` selects the manager configuration. Neither is demonstrated by offline mode, which returns `model_output=null`. Output files use exclusive creation; choose a new path and retain any failed or unknown attempt rather than blindly repeating a provider call.
