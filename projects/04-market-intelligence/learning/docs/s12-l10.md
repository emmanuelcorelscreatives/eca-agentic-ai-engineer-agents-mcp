# Memory and scope

ScopedMemory is application-owned bounded context with allowlisted keys, per-run access and reset. It is explicitly not a vector backend. memory_demo.py provides an opt-in actual CrewAI Memory remember/recall/reset probe with explicit embedder, fresh storage and provider authorization.

Implementation: `src/academy_market_debate/memory_demo.py`.

Observation status: offline checks may be run without credentials. SDK/provider/CLI/real memory runs are separately unexecuted unless accompanied by their own actual receipt.
