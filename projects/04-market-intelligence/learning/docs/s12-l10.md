# Actual crew memory and bounded explicit context

`ScopedMemory` in `core.py` is application-owned dictionary context. Its reset/isolation tests do not prove framework embedding retrieval. The original standalone `memory_demo.py` remains a separate optional probe.

`memory_integration.py` connects **CrewAI Memory** to the existing debate crew. `build_memory_crew` requires explicit authorization, an explicit embedder configuration, a fresh exclusive storage directory and a safe run ID. It constructs a Memory backend, creates `/academy/RUN/approved`, and gives every named role only that approved scoped view. Agents never receive a root or unrelated private view. Existing `build_crew` remains `memory=False` by default; no old caller silently starts embedding requests.

`run_memory_crew` stores the first fact from the exact loaded fixture in the approved scope, records genuine recall results, then executes the same configured tasks with their explicit context dependencies. It records actual task outputs and validates the verdict. Finally it resets only the approved scope and records a real subsequent recall; a nonempty result is held as a reset failure. It never deletes unrelated stores. Failed runs retain their owned store/evidence for diagnosis.

This optional example requires authorized model/embedding accounts and a finite budget; it is not a supplied successful run. Complete [uv setup](s11-l03.md), then from `projects/04-market-intelligence/learning` start Python with `PYTHONPATH=src uv run --frozen --extra crewai python` before entering:

```python
from academy_market_debate.memory_integration import run_memory_crew
report = run_memory_crew(
    model='PROVIDER/MODEL',
    fact_path='fixtures/retailer-facts.json',
    embedder={'provider': 'openai', 'config': {'model_name': 'text-embedding-3-large'}},
    storage='/your/new/owned/memory-run-01', run_id='run-01',
    authorize_provider=True,
)
```

Model and embedding credentials must be configured privately, never pasted into shared code or JSON. Scope views control what each agent can retrieve, but do not constitute an OS security boundary against arbitrary hostile Python code. Verify SDK acceptance of scoped objects, cross-scope denial, task reuse, recall and reset using actual outputs from your own run; none is established by the example alone.
