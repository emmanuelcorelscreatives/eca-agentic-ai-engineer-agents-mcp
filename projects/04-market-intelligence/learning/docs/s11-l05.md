# Project structure

config/ stores static roles and task contracts; core.py validates inputs; crew.py adapts real SDK objects; main.py owns command-line opt-in and result recording; fixtures/ owns original fictional data. Tool I/O and scheduling do not belong in YAML.

Implementation: `src/academy_market_debate/main.py`.

Observation status: offline checks may be run without credentials. SDK/provider/CLI/real memory runs are separately unexecuted unless accompanied by their own actual receipt.
