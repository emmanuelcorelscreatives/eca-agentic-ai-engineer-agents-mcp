# Stage 23 Lesson 09 solution: Add Human Approval

ApprovalBoundary intercepts the actual SDK function invocation and checks an immutable payload digest. The tool also consumes the trusted grant, defending direct native-tool invocation. Approval grants are supplied by the human/controller, never model arguments. The effect is explicitly a synthetic local outbox entry; no external send occurs.
