# Solution notes: s03-l02

Reference implementation: `chain, agent_loop` in `examples/stages02-04/foundations.py`; optional SDK implementation in the adjacent `sdk_adapter.py`.

No-tool loop uses one model call; demo tool loop uses two. Fixed workflows are preferable when steps are known; neither architecture guarantees factual correctness.

The full offline demo is reproducible with standard-library Python. The dedicated tests exercise success and negative boundaries; their PASS proves those code paths, not live model quality, named application installation or screenshot approval. Preserve this distinction in your submission.

Suggested discussion: Compare chain's fixed two-step order against the stock loop which can choose a tool or return immediately. Run a no-tool fixture then a tool fixture and compare call counts.
