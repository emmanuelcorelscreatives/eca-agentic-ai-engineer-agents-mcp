# Example comparison: research report versus browser task

For a fictional request to compare three documented learning tools, P03 Deep Research Intelligence Team (Stage 9) fits better than P06 Browser Task Sidekick (Stage 20). P03 accepts a bounded question and allowlisted sources; outputs a cited draft report; requires human publication review; and is evidenced by source register, report and actual missing-evidence tests. Its limitation is incomplete or outdated source coverage.

P06 accepts a task and course-owned practice website; outputs a resumable task trace; pauses before sensitive actions; and is evidenced by observed browser transitions, a checkpoint/resume test and an approval-boundary test. Its limitation is UI fragility and the narrow allowlisted environment. Neither preview proves a deployed system. The sales project requires delivery approval and the trading-floor practical remains paper-only, regardless of which project a learner selects.
