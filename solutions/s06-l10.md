# s06-l10: reference reasoning

`ObservationHooks` records actual model-call lifecycle durations, available SDK
usage and tool/handoff events without copying private inputs. Missing fields stay
null. `LocalSDKTraceProcessor` exports genuine SDK span IDs and parent links to a
new private local file; it replaces the hosted exporter unless hosted telemetry is
explicitly requested. Neither a local span nor a requested upload proves hosted
acceptance. The new span-redaction test uses real SDK trace objects without a model.

The failure remains visible; repaired runs do not overwrite failed evidence. Local trace fields use an allowlist, and SDK hosted tracing is disabled unless explicitly requested. Do not label LocalTrace events as a hosted trace screenshot.

Inspect `LocalTrace / catalogue_run` in `examples/stages06-07/`. Validate using `test_trace_correlation_privacy_and_complete_run` in `tests/test_stages_06_07.py`.

Do not copy expected output as observed evidence. Retain an actual run log and explain any failure. Offline test success proves application boundaries and deterministic behavior; it does not establish model accuracy, latency, token usage or hosted trace availability.
