# Reference solution: s18-l03

SQL predicates scope historical checkpoint reads by both ID and trusted thread. Missing thread and cross-thread checkpoint access fail; no model chooses another user session.

The runnable reference implementation is `examples/s18/durable_sessions.py` (`Sessions.load`). The behavior is exercised by `tests/test_stages16_19.py`.

Expected reasoning: Interleave A/B sentinel messages and reject a missing trusted thread ID.

Recording limitations: Trusted account-to-thread access control integration is application-specific and remains pending.
