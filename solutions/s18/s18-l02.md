# Reference solution: s18-l02

SQLite commits checkpoint rows plus head updates transactionally and closes connections. The actual unittest launches a fresh subprocess, proving persistence rather than a process-local dictionary.

The runnable reference implementation is `examples/s18/durable_sessions.py` (`Sessions.load`). The behavior is exercised by `tests/test_stages16_19.py`.

Expected reasoning: Write a checkpoint in one Python process, reopen in another and append a second turn.

Recording limitations: Native SqliteSaver close/reopen is separately opt-in; PostgreSQL dedicated course DB runtime pending.
