# Worked solution: s05-l10

The ChatInterface presents approved excerpts and citations, binds loopback by default and disables public sharing.

Implementation: `projects/01-digital-twin/app.py`. Relevant executable checks: `tests/test_projects_1_3.py`, `tests/test_stages_05_08.py`. Optional adapters require the listed environment and dependencies; they never send external mail. A fake-runner test proves application orchestration only, not model quality.

The implemented Gradio interface has separate session/action state, streaming answer progress, explicit consent and opportunity controls, contact receipts and saved-question controls. Repeated unchanged submission keeps its ID; “Start another” deliberately resets the ID and consent. Actual browser proof remains required.
