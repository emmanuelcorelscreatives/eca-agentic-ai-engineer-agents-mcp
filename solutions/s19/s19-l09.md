# Reference solution: s19-l09

Each write resolves against dedicated root, rejects parent traversal/absolute paths and symlink escapes, fsyncs a temporary file then replaces the destination. Course workspace is local and not a personal directory.

The runnable reference implementation is `examples/s19/browser_research.py` (`Workspace.write`). The behavior is exercised by `tests/test_stages16_19.py`.

Expected reasoning: Persist a plan/checkpoint and demonstrate traversal/symlink rejection against an outside sentinel.

Recording limitations: Hostile concurrent filesystem mutation is outside this single-user teaching fixture and requires OS isolation.
