# s06-l05: reference reasoning

Updated implementation: `consume_sdk_stream` records incomplete output, invokes
immediate cancellation and drains the same SDK iterator. UI cancellation and
caller-task cancellation are distinct; the latter propagates after cleanup.
Empty/unknown events do not create text, and partial failures never become final
answers. New semantic tests use labelled event fixtures; actual provider streaming
must still be observed separately before making a model-streaming claim.

The first event selects the catalogue agent and the last event signals completion only in the deterministic fixture. Real stream_events() event types are inspected as emitted; non-text events must never be printed as invented speech.

Inspect `offline_stream / run_live(stream=True)` in `examples/stages06-07/`. Validate using `test_synthetic_stream_typed_and_ordered` in `tests/test_stages_06_07.py`.

Do not copy expected output as observed evidence. Retain an actual run log and explain any failure. Offline test success proves application boundaries and deterministic behavior; it does not establish model accuracy, latency, token usage or hosted trace availability.
