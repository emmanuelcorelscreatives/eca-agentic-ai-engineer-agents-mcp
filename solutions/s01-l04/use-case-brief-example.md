# Example fictional brief: brief-research / P03

User: an Academy Practice Cooperative researcher comparing three learning tools. Inputs: a bounded research question and public documentation pages whose URLs and access dates are recorded. Output: a draft comparison report with source-linked claims, contradictions and uncertainties.

Allowed tools: read allowlisted public documents and write local draft files. Forbidden: private accounts, outbound messages, purchases and unrestricted code execution. A person reviews source adequacy and report content before publication. Acceptance: every factual comparison links a retained source; missing evidence is marked unknown; conflicting claims are shown; actual test logs demonstrate missing-source handling. Retain the question, source register, dated extracts, exact model run when used, report and test output. Exclude a claim of comprehensive market coverage or employment outcomes.
