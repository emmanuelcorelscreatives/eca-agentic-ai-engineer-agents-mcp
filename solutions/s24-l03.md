# Reference walkthrough: s24-l03

Inspect lookup_ticket, search_articles and the Pydantic output schema. Unknown tickets return an error and cannot become invented summaries.

Use the shared `triage_schema()` for both direct-tool and MCP Agno factories.
It checks actual same-product fixture IDs as well as required fields; `A-999`,
another product's article, duplicate IDs and absent evidence fail. Bind the
original request explicitly with
`validate_triage_response(result.content, requested_ticket_id=original_ticket_id)`.
The response fields are `ticket_id`, `summary`, `article_ids` and `unresolved`;
there is no priority field. Citation membership alone is not a model retrieval
trace or factual approval of free-text prose.
