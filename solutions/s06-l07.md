# s06-l07: reference reasoning

The catalogue is the canonical exercise. The decorated tool now passes its return
through strict `CatalogueToolResult`/`CatalogueRecord` validation and then compares
it to the requested current record. A final-answer schema alone does not protect
the tool-return boundary. Unknown course means `found=False, course=None`; a
well-typed invented title or another ID's record must also fail factual binding.
See the authored structured-return semantic test; execution remains central QA's
responsibility and is not claimed by this source change.

Schema compliance alone does not prove a course fact. Catalogue lookup is authoritative for known IDs; output schema requires a typed result, while application code rejects unexpected catalogue fields and malformed source data.

Inspect `Course.parse / CourseAnswer` in `examples/stages06-07/`. Validate using `test_schema_rejects_invalid_extra_and_level` in `tests/test_stages_06_07.py`.
