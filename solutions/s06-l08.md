# s06-l08: reference reasoning

SQLiteHistory is an explicitly app-owned comparison store. Actual SQLiteSession is separately tested. Each session ID selects its own history; sharing an ID deliberately shares memory and must not be confused with user authentication.

Inspect `SQLiteHistory / SQLiteSession` in `examples/stages06-07/`. Validate using `test_memory_persists_across_instances_and_isolates_sessions` in `tests/test_stages_06_07.py`.

Do not copy expected output as observed evidence. Retain an actual run log and explain any failure. Offline test success proves application boundaries and deterministic behavior; it does not establish model accuracy, latency, token usage or hosted trace availability.
