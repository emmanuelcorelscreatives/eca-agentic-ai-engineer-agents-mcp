# Solution notes: s02-l02

Reference implementation: `environment_report` in `examples/stages02-04/foundations.py`; optional SDK implementation in the adjacent `sdk_adapter.py`.

Actual Windows commands must be observed on Windows. Check the executable belongs to the virtual environment. This Linux-authored fixture does not prove a Windows installation.

The full offline demo is reproducible with standard-library Python. The dedicated tests exercise success and negative boundaries; their PASS proves those code paths, not live model quality, named application installation or screenshot approval. Preserve this distinction in your submission.

Suggested discussion: On Windows PowerShell run `py -0p`, `py -3 --version`, `uv --version`, `git --version`; create a virtual environment and activate `.venv\Scripts\Activate.ps1`. Select that interpreter before running the demo. If activation policy blocks a script, invoke `.venv\Scripts\python.exe` directly rather than changing machine-wide policy.
