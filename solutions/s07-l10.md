# s07-l10: reference reasoning

Parent IDs bind local spans and request attribution. Sensitive free text is excluded from local traces. Real SDK hosted traces require a real opt-in run and trace privacy settings; no offline event should be presented as a hosted trace result.

Inspect `LocalTrace / specialists` in `examples/stages06-07/`. Validate using `test_trace_correlation_privacy_and_complete_run` in `tests/test_stages_06_07.py`.

Do not copy expected output as observed evidence. Retain an actual run log and explain any failure. Offline test success proves application boundaries and deterministic behavior; it does not establish model accuracy, latency, token usage or hosted trace availability.
