# Solution notes: s04-l07

Reference implementation: `agent_loop` in `examples/stages02-04/foundations.py`; optional SDK implementation in the adjacent `sdk_adapter.py`.

A framework is not an inference engine; MCP is not automatic tool permission. This exercise provides architecture comparison, not runnable integrations with every named framework.

The full offline demo is reproducible with standard-library Python. The dedicated tests exercise success and negative boundaries; their PASS proves those code paths, not live model quality, named application installation or screenshot approval. Preserve this distinction in your submission.

Suggested discussion: Map the shipped plain-Python loop to model provider, orchestration, tool contract, protocol and tracing responsibilities. Classify Agents SDK/LangGraph, Ollama, MCP and a trace store by their actual roles using official docs.
