# s06-l08: Add Conversation Memory with Sessions

Objective: Preserve conversation history so an agent can maintain continuity across multiple interactions.

Use Python 3.10 or newer. All data in `data/s06-catalogue.json` and `data/s07-support-cases.json` is synthetic Academy teaching data. No customer records or live provider results are included.

## Work

Create two separate conversation sessions, add a course choice to one and verify it is absent in the other. Explain replay history versus session-managed history and avoid passing both copies to a run.

Implementation to inspect: `examples/stages06-07/workflows.py` and `examples/stages06-07/sdk_adapter.py`, symbols `SQLiteHistory / SQLiteSession`.

## Run and check

From the repository root:

```sh
python3 -m unittest discover -s tests -p test_stages_06_07.py -v
python3 examples/stages06-07/workflows.py --stage 6
```

Relevant acceptance check: `test_memory_persists_across_instances_and_isolates_sessions`. Optional actual SDK construction/storage tests require `examples/stages06-07/requirements.txt`; without it those checks are explicitly skipped. Inspect the test assertions, make one deliberate regression and confirm the matching check fails before restoring it.
