# s06-l01: Introduction to the OpenAI Agents SDK

Objective: Introduce the SDK’s role in building tool-using, observable and coordinated agent applications.

Use Python 3.10 or newer. All data in `data/s06-catalogue.json` and `data/s07-support-cases.json` is synthetic Academy teaching data. No customer records or live provider results are included.

## Work

Draw model, Runner, function tool, app-owned catalogue and trace boundaries. Classify lookup validation as application code and generation as a model service. Explain why installing the SDK does not grant model credits.

Implementation to inspect: `examples/stages06-07/workflows.py` and `examples/stages06-07/sdk_adapter.py`, symbols `catalogue_run / make_agents`.

## Run and check

From the repository root:

```sh
python3 -m unittest discover -s tests -p test_stages_06_07.py -v
python3 examples/stages06-07/workflows.py --stage 6
```

Relevant acceptance check: `test_run_envelope_and_failure_trace`. Optional actual SDK construction/storage tests require `examples/stages06-07/requirements.txt`; without it those checks are explicitly skipped. Inspect the test assertions, make one deliberate regression and confirm the matching check fails before restoring it.
