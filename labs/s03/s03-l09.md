# s03-l09: Agentic AI Risks, Failure Modes and Common Traps

Examine hallucination, loops, tool misuse, prompt injection, excessive autonomy and uncontrolled cost.

## Run and inspect

From repository root: `python3 examples/stages02-04/foundations.py`. On Windows use `py -3` when appropriate. Inspect `execute_tool, agent_loop` in `examples/stages02-04/foundations.py` (SDK class in `sdk_adapter.py`).

Try an unknown delete tool, an extra shell argument, a repeated tool-call ID and a response containing prompt-injection text. Identify what allowlisting blocks and what it cannot prove.

## Deliverable

Submit your changed experiment, redacted actual output, and a short explanation of what remains untested. Never include credentials. Reset by deleting only your own temporary output/virtual environment; do not delete repository fixtures.

## Acceptance rubric

Unknown tools, extra arguments and repeated IDs fail. Treating content as data reduces privileges but does not solve semantic prompt injection; consequential actions need a separate permission/approval boundary.

Run `python3 -m unittest discover -s tests -p test_stages_02_04.py -v`. Fixtures are labelled synthetic; live vendor/app setup and screenshots require separate actual execution. See `solutions/s03/s03-l09.md` after attempting the task.
