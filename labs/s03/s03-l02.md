# s03-l02: AI Agents vs Deterministic Workflows

Compare flexible agent behavior with predictable workflows and identify when each approach is appropriate.

## Run and inspect

From repository root: `python3 examples/stages02-04/foundations.py`. On Windows use `py -3` when appropriate. Inspect `chain, agent_loop` in `examples/stages02-04/foundations.py` (SDK class in `sdk_adapter.py`).

Compare chain's fixed two-step order against the stock loop which can choose a tool or return immediately. Run a no-tool fixture then a tool fixture and compare call counts.

## Deliverable

Submit your changed experiment, redacted actual output, and a short explanation of what remains untested. Never include credentials. Reset by deleting only your own temporary output/virtual environment; do not delete repository fixtures.

## Acceptance rubric

No-tool loop uses one model call; demo tool loop uses two. Fixed workflows are preferable when steps are known; neither architecture guarantees factual correctness.

Run `python3 -m unittest discover -s tests -p test_stages_02_04.py -v`. Fixtures are labelled synthetic; live vendor/app setup and screenshots require separate actual execution. See `solutions/s03/s03-l02.md` after attempting the task.
