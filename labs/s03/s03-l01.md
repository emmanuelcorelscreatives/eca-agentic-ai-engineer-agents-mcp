# s03-l01: What Is an AI Agent?

Define an AI agent in terms of objectives, reasoning, tools, state, feedback and environmental interaction.

## Run and inspect

From repository root: `python3 examples/stages02-04/foundations.py`. On Windows use `py -3` when appropriate. Inspect `agent_loop` in `examples/stages02-04/foundations.py` (SDK class in `sdk_adapter.py`).

Draw objective, observations, state, action and stop condition for a stock-answering agent. Run demo() and label each message with its role. Distinguish a model request for a tool from application execution of that tool.

## Deliverable

Submit your changed experiment, redacted actual output, and a short explanation of what remains untested. Never include credentials. Reset by deleting only your own temporary output/virtual environment; do not delete repository fixtures.

## Acceptance rubric

The model asks for stock, Python validates arguments, the tool yields a synthetic result and the model produces a final answer. There is no autonomous network, shell or write permission.

Run `python3 -m unittest discover -s tests -p test_stages_02_04.py -v`. Fixtures are labelled synthetic; live vendor/app setup and screenshots require separate actual execution. See `solutions/s03/s03-l01.md` after attempting the task.
