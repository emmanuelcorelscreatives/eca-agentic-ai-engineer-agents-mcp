# s03-l04: Prompt Chaining and Sequential Workflows

Build workflows in which model calls and software operations execute in a controlled sequence.

## Run and inspect

From repository root: `python3 examples/stages02-04/foundations.py`. On Windows use `py -3` when appropriate. Inspect `chain` in `examples/stages02-04/foundations.py` (SDK class in `sdk_adapter.py`).

Change the synthetic product note to request a PDF export and supply matching fixture requirements/checklist. Capture both intermediate and final text and then test invalid first output.

## Deliverable

Submit your changed experiment, redacted actual output, and a short explanation of what remains untested. Never include credentials. Reset by deleting only your own temporary output/virtual environment; do not delete repository fixtures.

## Acceptance rubric

Recorded second prompt must contain the exact validated first text. No test claims that live models always obey the requested format.

Run `python3 -m unittest discover -s tests -p test_stages_02_04.py -v`. Fixtures are labelled synthetic; live vendor/app setup and screenshots require separate actual execution. See `solutions/s03/s03-l04.md` after attempting the task.
