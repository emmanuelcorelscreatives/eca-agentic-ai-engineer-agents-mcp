## Stable UI startup and mode contract

Follow the [integrated fixture interaction recipe](../../projects/06-browser-sidekick/BROWSER-LABS.md) for step-by-step practice. Restart preserves only the same database's exact owned sandbox endpoint and synthetic receipts. An occupied port or legacy task without persisted identity fails closed; do not rewrite origins, transfer approval, or automatically renew expired decisions.

From the repository root, prepare the separate environment in the [stage 16 guide](../s16/README.md), install Chromium, and choose fresh private state paths:

```sh
python -m playwright install chromium
python projects/06-browser-sidekick/ui_gradio.py --database /tmp/academy-sidekick-ui.sqlite --workspace-root /tmp/academy-sidekick-workspaces --port 7860
```

On Windows replace both `/tmp` paths with writable local paths. Open `http://127.0.0.1:7860`, create a synthetic workshop task, advance it, inspect the browser/result panels, and exercise approve/reject only for the exact displayed practice action. With no `--model`, the planner is visibly a deterministic fixture; Chromium still needs to be installed for the real local browser path. Keep this server loopback-only and close it after practice. Reuse the same database/workspace only to resume that owned session; do not silently replace its sandbox identity.

For an explicitly budgeted native-model experiment, configure the provider credentials privately and add `--model provider:model` with a real available model identifier. This enables potentially billable planning; missing configuration or a native-model failure is not permission to silently substitute fixture output.

The actual entrypoint is `projects/06-browser-sidekick/ui_gradio.py`. `build_ui(database, sandbox, *, model=None, workspace_root=None, executable_path=None, application=None)` uses the same integrated application. A configured native run passes an explicit `--model provider:model`; omitting it deliberately selects the visibly labeled deterministic fixture, with no silent fallback after a native error. `--database`, `--workspace-root` and optional `--browser-executable` bind owned local state and the admitted installed Chromium. The server binds loopback with public sharing disabled.
