# s17-l06: Create Conditional Edges

Route execution according to model decisions, state values or deterministic application rules.

## Coherent course case and actual source

## Practical exercise

Create the empty/supported/unsupported route decision table and exercise all three through actual native conditional edges.

## Acceptance and reference reasoning

Empty or invalid requests clarify, a supported normalized sidekick request performs lookup and unsupported products finish with an honest unavailable response. Deterministic rules satisfy this routing objective; a model decision is not required.
