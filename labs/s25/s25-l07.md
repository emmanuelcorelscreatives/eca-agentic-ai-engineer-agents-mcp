Produce focused agent instructions that define role, behavior, boundaries and tool-use policy.

## Coherent practical case

A typed Academy catalog-research/draft-notification agent specification. Generated requirements, architecture, tools, instructions, tests and reviews must feed the same approved dependency graph and produce a real runnable selected-framework project.

## Source map

Project root: `projects/07-agent-factory`. Baseline source anchors: `advanced.py: instructions`. Read the current integrated module listed in the stage workbook as well; baseline helpers alone do not prove full application integration.

## Exercise

Generate focused role, behavior, boundaries and tool-use instructions from the approved requirements and review their policy consistency.

## Acceptance and reasoning

A model prompt generator may propose prose but cannot change immutable application permissions, expand the allowed tools or remove human approval requirements. Preserve the source spec and acceptance IDs in the handoff; do not confuse a static instruction template with observed generated instructions.

## Verify your result

Record the command, dependency versions and actual result when you run this exercise. Expected results are not observations. Offline fixtures, SDK construction, model responses, browser interactions and Docker execution verify different things; report skips and failures honestly.
