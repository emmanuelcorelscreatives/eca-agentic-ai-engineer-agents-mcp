# s02-l02: Windows Development Environment Setup

Install and configure the required development tools on Windows and verify that each tool works correctly.

## Run and inspect

From repository root: `python3 examples/stages02-04/foundations.py`. On Windows use `py -3` when appropriate. Inspect `environment_report` in `examples/stages02-04/foundations.py` (SDK class in `sdk_adapter.py`).

On Windows PowerShell run `py -0p`, `py -3 --version`, `uv --version`, `git --version`; create a virtual environment and activate `.venv\Scripts\Activate.ps1`. Select that interpreter before running the demo. If activation policy blocks a script, invoke `.venv\Scripts\python.exe` directly rather than changing machine-wide policy.

## Deliverable

Submit your changed experiment, redacted actual output, and a short explanation of what remains untested. Never include credentials. Reset by deleting only your own temporary output/virtual environment; do not delete repository fixtures.

Actual Windows commands must be observed on Windows. Check the executable belongs to the virtual environment. This Linux-authored fixture does not prove a Windows installation.
