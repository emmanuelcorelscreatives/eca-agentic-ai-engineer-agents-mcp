# s02-l07: Make Your First Model API Call in Python

Send a prompt from Python, inspect the response and understand the basic request-response lifecycle.

## Run and inspect

From repository root: `python3 examples/stages02-04/foundations.py`. On Windows use `py -3` when appropriate. Inspect `text_call, FakeModel, CompatibleModel` in `examples/stages02-04/foundations.py` (SDK class in `sdk_adapter.py`).

Call text_call with FakeModel([{'content':'Hello academy'}]) and Budget(1). Inspect recorded requests. Read the SDK and HTTP adapters. Optionally make one explicitly opted-in hosted request with synthetic text and retain redacted output/usage.

## Deliverable

Submit your changed experiment, redacted actual output, and a short explanation of what remains untested. Never include credentials. Reset by deleting only your own temporary output/virtual environment; do not delete repository fixtures.
