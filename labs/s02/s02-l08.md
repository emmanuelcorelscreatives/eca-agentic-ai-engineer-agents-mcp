# s02-l08: Chain Multiple Model Calls into a Workflow

Pass the output of one model call into another to create a simple multi-step workflow.

## Run and inspect

From repository root: `python3 examples/stages02-04/foundations.py`. On Windows use `py -3` when appropriate. Inspect `chain` in `examples/stages02-04/foundations.py` (SDK class in `sdk_adapter.py`).

Run chain with two fixture outputs: CSV export, then a checklist. Inspect requests[1] and prove it contains CSV export. Replace the first fixture content with an empty string and run again.

## Deliverable

Submit your changed experiment, redacted actual output, and a short explanation of what remains untested. Never include credentials. Reset by deleting only your own temporary output/virtual environment; do not delete repository fixtures.

## Acceptance rubric

The valid intermediate is passed to step two. Empty first content raises ValueError after exactly one recorded request, with no second fixture consumed.

Run `python3 -m unittest discover -s tests -p test_stages_02_04.py -v`. Fixtures are labelled synthetic; live vendor/app setup and screenshots require separate actual execution. See `solutions/s02/s02-l08.md` after attempting the task.
