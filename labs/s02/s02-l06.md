## Usage envelope and stop worksheet

Use `Observation`, `observation_from_response`, `UsageLedger` and `example_cost` in `stage02_configuration.py`. An actual `ObservedCompatibleModel.observe` response retains sanitized provider request ID, model, reported input/output tokens and a distinct usage status. The test envelope is synthetic.

Worksheet columns: local request ID; provider request ID if actually supplied; model; input/output token reservation; reported input/output tokens or **UNKNOWN**; explicitly dated chosen prices per million; illustrative calculated cost; remaining planned capacity; stop reason. Reserve before transport, record reported usage after response, or `record_unknown` after an ambiguous request. Missing usage halts future admission and remains unknown, never zero. A reported overrun also halts future admission.

For synthetic 1000 input/2000 output at illustrative prices 1/2 per million, cost is exactly 0.005. Show request cap, planned token/cost refusal, missing usage and observed overrun. Reservations are estimates/application admission limits; they do not constrain provider tokenization or guarantee a billing hard cap.
