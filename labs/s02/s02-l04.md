# s02-l04: Configure Your IDE with Cursor or Visual Studio Code

Prepare the editor, terminal, Python interpreter and recommended extensions for the course projects.

## Run and inspect

From repository root: `python3 examples/stages02-04/foundations.py`. On Windows use `py -3` when appropriate. Inspect `environment_report` in `examples/stages02-04/foundations.py` (SDK class in `sdk_adapter.py`).

Open the repository in VS Code or Cursor. Select the `.venv` Python interpreter, open an integrated terminal, run the demo and set a breakpoint in text_call. Inspect the prompt and Budget.calls before and after a fixture call.

## Deliverable

Submit your changed experiment, redacted actual output, and a short explanation of what remains untested. Never include credentials. Reset by deleting only your own temporary output/virtual environment; do not delete repository fixtures.

## Acceptance rubric

Show the actual selected interpreter and stopped frame. A correct run prints OFFLINE SYNTHETIC. Editor screenshots and extensions require real editor execution, not our test output.

Run `python3 -m unittest discover -s tests -p test_stages_02_04.py -v`. Fixtures are labelled synthetic; live vendor/app setup and screenshots require separate actual execution. See `solutions/s02/s02-l04.md` after attempting the task.
