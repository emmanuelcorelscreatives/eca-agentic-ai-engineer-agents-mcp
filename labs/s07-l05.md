# s07-l05: Build a Manager-Agent Architecture

Objective: Create a manager that plans work, selects specialists and assembles a final response.

Use Python 3.10 or newer. All data in `data/s06-catalogue.json` and `data/s07-support-cases.json` is synthetic Academy teaching data. No customer records or live provider results are included.

## Work

Build a support response from the research stock and policy result. Deliberately fail research and ensure no stock is invented. Compare the deterministic synthesis envelope with the typed manager live output.

Implementation to inspect: `examples/stages06-07/workflows.py` and `examples/stages06-07/sdk_adapter.py`, symbols `specialists / SupportAnswer`.

## Run and check

From the repository root:

```sh
python3 -m unittest discover -s tests -p test_stages_06_07.py -v
python3 examples/stages06-07/workflows.py --stage 7
```

Relevant acceptance check: `test_cross_request_and_invalid_schema_become_honest_partial`. Optional actual SDK construction/storage tests require `examples/stages06-07/requirements.txt`; without it those checks are explicitly skipped. Inspect the test assertions, make one deliberate regression and confirm the matching check fails before restoring it.
