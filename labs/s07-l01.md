# s07-l01: Single-Agent vs Multi-Agent Architecture

Objective: Determine when specialist agents improve a system and when one agent remains the better design.

Use Python 3.10 or newer. All data in `data/s06-catalogue.json` and `data/s07-support-cases.json` is synthetic Academy teaching data. No customer records or live provider results are included.

## Work

Use REQ-001 to compare direct application lookup with two specialists. Count boundaries and local events, then identify a reason to split roles that is independent of an invented speedup.

Implementation to inspect: `examples/stages06-07/workflows.py` and `examples/stages06-07/sdk_adapter.py`, symbols `orchestration_comparison`.

## Run and check

From the repository root:

```sh
python3 -m unittest discover -s tests -p test_stages_06_07.py -v
python3 examples/stages06-07/workflows.py --stage 7
```

Relevant acceptance check: `test_comparison_never_claims_provider_benchmark`. Optional actual SDK construction/storage tests require `examples/stages06-07/requirements.txt`; without it those checks are explicitly skipped. Inspect the test assertions, make one deliberate regression and confirm the matching check fails before restoring it.
