# s06-l09: Persist Agent Sessions with SQLite

Objective: Store session state in SQLite and restore conversations after the application restarts.

Use Python 3.10 or newer. All data in `data/s06-catalogue.json` and `data/s07-support-cases.json` is synthetic Academy teaching data. No customer records or live provider results are included.

## Work

Save two turns to a temporary SQLite file, close the first store and construct another using the same path and session. Verify restart persistence and isolated clear_session behavior. Never use a real learner conversation.

Implementation to inspect: `examples/stages06-07/workflows.py` and `examples/stages06-07/sdk_adapter.py`, symbols `SQLiteHistory / SQLiteSession`.

## Run and check

From the repository root:

```sh
python3 -m unittest discover -s tests -p test_stages_06_07.py -v
python3 examples/stages06-07/workflows.py --stage 6
```

Relevant acceptance check: `test_actual_sdk_sqlite_session_restart_and_isolation`. Optional actual SDK construction/storage tests require `examples/stages06-07/requirements.txt`; without it those checks are explicitly skipped. Inspect the test assertions, make one deliberate regression and confirm the matching check fails before restoring it.

## Deliverable

Run seed and followup as separate processes with the same new SQLite file and
session ID; use the unrelated control to inspect isolation. The new contract test
launches separate real SDK Runner processes with a labelled synthetic Model. An
authorized live dialogue uses the same code path with an actual configured model;
its observed answers must be retained separately. Do not hand-insert history,
silently carry an in-memory object across a supposed restart, or publish the DB.

Submit your change, actual terminal output, the source of each reported fact and one limitation. Separate local deterministic events from SDK object behavior and actual model observations. Any lesson claim about model delegation, streamed model content or hosted traces remains pending an authorized live run. See `examples/stages06-07/README.md` for opt-in instructions.
