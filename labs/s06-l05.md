# s06-l05: Stream Agent Responses

Objective: Deliver incremental output and execution updates while an agent run is in progress.

Use Python 3.10 or newer. All data in `data/s06-catalogue.json` and `data/s07-support-cases.json` is synthetic Academy teaching data. No customer records or live provider results are included.

## Work

Consume synthetic stream events and reconstruct the JSON from raw deltas. In an authorized live run send typed event kinds to stderr and only actual output_text deltas to stdout. Cancel an interrupted stream and record the interruption, not a fabricated completion.

Implementation to inspect: `examples/stages06-07/workflows.py` and `examples/stages06-07/sdk_adapter.py`, symbols `offline_stream / run_live(stream=True)`.

## Run and check

From the repository root:

```sh
python3 -m unittest discover -s tests -p test_stages_06_07.py -v
python3 examples/stages06-07/workflows.py --stage 6
```

Relevant acceptance check: `test_synthetic_stream_typed_and_ordered`. Optional actual SDK construction/storage tests require `examples/stages06-07/requirements.txt`; without it those checks are explicitly skipped. Inspect the test assertions, make one deliberate regression and confirm the matching check fails before restoring it.

## Added interruption exercise

Inspect `stream_receipt.py`. Its consumer is used by the real `run_streamed` path.
Use explicitly synthetic event sources to test an empty stream, unknown event,
partial text followed by an exception, user cancellation after one delta, and
caller task cancellation. Preserve `partial_text`, `error_type`, status and
`cleanup_complete`; never promote a failed/cancelled receipt to a final answer.
Verify cancellation drains the same iterator and no replacement run is started.
The new semantic repair tests are authored for central QA, not already executed.
Real provider streaming evidence remains separate and budgeted; concept-only
event-handling lessons do not require a paid run to prove these Python boundaries.

## Deliverable

Submit your change, actual terminal output, the source of each reported fact and one limitation. Separate local deterministic events from SDK object behavior and actual model observations. Any lesson claim about model delegation, streamed model content or hosted traces remains pending an authorized live run. See `examples/stages06-07/README.md` for opt-in instructions.
