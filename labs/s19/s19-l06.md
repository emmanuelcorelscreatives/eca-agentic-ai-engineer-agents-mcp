# s19-l06: Connect Playwright Through MCP

Expose browser capabilities through MCP and call them from an agent client.

## Actual repository implementation

Read `examples/s19/browser_research.py` → `create_browser_mcp`. Run from repository root:

```sh
python -m pip install "mcp>=1.20,<2"
python -m playwright install chromium
python -m examples.s19.mcp_client_demo
```

Use the separate environment from [lesson 2](s19-l02.md). The client starts the owned synthetic fixture server and an MCP stdio child with the same Python interpreter, initializes a real session, lists the registered `inspect_page` schema and calls it for `/docs.html`. Expected: actual discovered schema and actual page-tool result, labelled synthetic fixture/no model call. Missing SDK/browser, a tool error or timeout is not a successful protocol run. Both contexts clean up on exit. This does not contact a paid model or any third-party website.

To inspect the standalone server with another MCP client, its executable route is `python -m examples.s19.browser_research --mcp --origin <your-owned-loopback-origin>`. A waiting stdio server by itself is not client discovery or tool-call evidence. Do not connect it to a personal browser profile or private application.

## Acceptance and evidence

The server exposes a bounded read-only operation; each call gets a fresh browser context and local-origin request restrictions. Tool schemas come from actual FastMCP registration, not hand-written fake MCP responses.

`inspect_page` is asynchronous at the MCP boundary and awaits
`asyncio.to_thread(inspect_sync)`. The synchronous Playwright context opens,
navigates, reads and closes entirely on that worker. Do not call the synchronous
Playwright API directly inside MCP's running event loop or share its page across
threads. A direct browser read is distinct from a real MCP client tool call.

Retain the command, actual output and relevant negative-case evidence. Fixture runs are explicitly deterministic, not provider observations. Capture only genuine application/terminal views from the tested code.
