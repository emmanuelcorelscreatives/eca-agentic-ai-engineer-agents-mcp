# s19-l02: Set Up Playwright for Browser Control

Install the browser runtime and verify navigation through a controlled automation script.

## Actual repository implementation

Read `examples/s19/browser_research.py` → `run_browser_demo`. Run from repository root:

Create and activate the separate environment in the [stage 16 guide](../s16/README.md), then install Chromium and run the actual browser path:

```sh
python -m playwright install chromium
python -m examples.s19.browser_research --browser-screenshot /tmp/academy-s19-browser.png
```

Choose a new writable screenshot path; on Windows replace `/tmp/academy-s19-browser.png` with a local path. Expected: JSON with the real local navigation, extracted synthetic records and prepared synthetic form, plus a PNG from the actual page. The command owns and closes its loopback fixture server and browser. No website account, model call or form submission is involved. Opening the PNG and checking its contents is a separate learner check; a unit-test pass alone does not demonstrate browser installation.

The supporting dependency-free checks are `python -m unittest discover -s tests -p test_stages16_19.py -v`.
