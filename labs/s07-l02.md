# s07-l02: Orchestration by Code vs Orchestration by the Model

Objective: Compare deterministic application-controlled coordination with flexible model-controlled delegation.

Use Python 3.10 or newer. All data in `data/s06-catalogue.json` and `data/s07-support-cases.json` is synthetic Academy teaching data. No customer records or live provider results are included.

## Work

Compare code-controlled gather with a manager whose only capabilities are two specialist tools. List who decides routing and owns the answer. For live mode record actual invoked tools rather than assuming both were selected.

Implementation to inspect: `examples/stages06-07/workflows.py` and `examples/stages06-07/sdk_adapter.py`, symbols `specialists / make_agents.manager`.

## Run and check

From the repository root:

```sh
python3 -m unittest discover -s tests -p test_stages_06_07.py -v
python3 examples/stages06-07/workflows.py --stage 7
```

Relevant acceptance check: `test_as_tool_manager_ownership_vs_handoff_ownership`. Optional actual SDK construction/storage tests require `examples/stages06-07/requirements.txt`; without it those checks are explicitly skipped. Inspect the test assertions, make one deliberate regression and confirm the matching check fails before restoring it.

Submit your change, actual terminal output, the source of each reported fact and one limitation. Separate local deterministic events from SDK object behavior and actual model observations.
