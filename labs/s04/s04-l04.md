# s04-l04: Run Local Models with Ollama

Install Ollama, launch a local model and call it from a Python application.

## Run and inspect

From repository root: `python3 examples/stages02-04/foundations.py`. On Windows use `py -3` when appropriate. Inspect `OllamaModel` in `examples/stages02-04/foundations.py` (SDK class in `sdk_adapter.py`).

Install Ollama from its official site, pull an explicitly selected model suitable for available memory, run ollama list and send one short local text call. First run the fake-transport test to understand stream=false and num_predict.
