# s04-l01: Comparing Hosted and Local Language Models

Compare hosted and local models across quality, privacy, speed, hardware requirements and cost.

## Run and inspect

From repository root: `python3 examples/stages02-04/foundations.py`. On Windows use `py -3` when appropriate. Inspect `CompatibleModel, OllamaModel` in `examples/stages02-04/foundations.py` (SDK class in `sdk_adapter.py`).

Compare a hosted request path and the local loopback path. Record privacy boundary, model footprint, cold-start latency, throughput and maintenance requirements. Use synthetic observations only until you run each real model.

## Deliverable

Submit your changed experiment, redacted actual output, and a short explanation of what remains untested. Never include credentials. Reset by deleting only your own temporary output/virtual environment; do not delete repository fixtures.

## Acceptance rubric

A local endpoint alone does not prove all data remains private; inspect runtime/model-download and logging behavior. No synthetic table is evidence of product superiority.

Run `python3 -m unittest discover -s tests -p test_stages_02_04.py -v`. Fixtures are labelled synthetic; live vendor/app setup and screenshots require separate actual execution. See `solutions/s04/s04-l01.md` after attempting the task.
