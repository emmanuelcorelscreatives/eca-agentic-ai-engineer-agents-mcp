Map major frameworks, visual builders, runtimes, protocols and observability platforms to their roles.

## Run and inspect

From repository root: `python3 examples/stages02-04/foundations.py`. On Windows use `py -3` when appropriate. Inspect `agent_loop` in `examples/stages02-04/foundations.py` (SDK class in `sdk_adapter.py`).

Submit your changed experiment, redacted actual output, and a short explanation of what remains untested. Never include credentials. Reset by deleting only your own temporary output/virtual environment; do not delete repository fixtures.

A framework is not an inference engine; MCP is not automatic tool permission. This exercise provides architecture comparison, not runnable integrations with every named framework.

Run `python3 -m unittest discover -s tests -p test_stages_02_04.py -v`. Fixtures are labelled synthetic; live vendor/app setup and screenshots require separate actual execution. See `solutions/s04/s04-l07.md` after attempting the task.
