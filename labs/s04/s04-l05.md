# s04-l05: Select Models by Capability, Cost, Speed and Reliability

Develop a repeatable model-selection process based on the requirements of a specific agent task.

## Run and inspect

From repository root: `python3 examples/stages02-04/foundations.py`. On Windows use `py -3` when appropriate. Inspect `select_model` in `examples/stages02-04/foundations.py` (SDK class in `sdk_adapter.py`).

Load the labelled synthetic model observations, apply quality>=4 and latency<=5 seconds, choose the lowest illustrative cost among eligible rows, and test an impossible quality threshold. Replace fixtures with your measured observations for a real selection.

## Deliverable

Submit your changed experiment, redacted actual output, and a short explanation of what remains untested. Never include credentials. Reset by deleting only your own temporary output/virtual environment; do not delete repository fixtures.

## Acceptance rubric

Synthetic-a is selected; threshold 5 yields None. Quality and latency must be measured with the same task/rubric; sample cost is not current pricing.

Run `python3 -m unittest discover -s tests -p test_stages_02_04.py -v`. Fixtures are labelled synthetic; live vendor/app setup and screenshots require separate actual execution. See `solutions/s04/s04-l05.md` after attempting the task.
