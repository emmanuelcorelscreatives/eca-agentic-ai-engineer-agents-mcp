Pause external delivery until a user approves, edits or rejects the final message.

Approve then edit and retry delivery; inspect reject UI path.

Read `projects/02-sales-team/sales.py` and its project README. Use synthetic fixtures only. Run `python3 -m unittest discover -s tests -p test_stages_05_08.py -v` and the project CLI. Distinguish offline observations from live SDK/browser/deployment work; do not claim unexecuted outcomes.

## Acceptance

Editing clears approval/hash. UI rejection records rejected. The displayed message must match the exact stored payload before approval.

Record the actual command, observed output and any unmet named application requirement.

## Required exact approval exercise

Through the same application, generate, preview, approve, then change recipient alone; approval must be revoked. Repeat with body and subject. Attempt approval from a stale displayed revision/hash.
