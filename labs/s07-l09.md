# s07-l09: Handle Multi-Agent Failures

Objective: Add timeouts, retries, fallbacks and partial-result handling to coordinated agent runs.

Use Python 3.10 or newer. All data in `data/s06-catalogue.json` and `data/s07-support-cases.json` is synthetic Academy teaching data. No customer records or live provider results are included.

## Work

Inject transient errors, permanent errors, a timeout and invalid schemas independently. Count actual calls, verify cancellation cleanup and print a partial result without pretending fallback text is verified policy.

Implementation to inspect: `examples/stages06-07/workflows.py` and `examples/stages06-07/sdk_adapter.py`, symbols `bounded_read / specialists`.

From the repository root:

```sh
python3 -m unittest discover -s tests -p test_stages_06_07.py -v
python3 examples/stages06-07/workflows.py --stage 7
```

Relevant acceptance check: `test_transient_only_bounded_retries`. Optional actual SDK construction/storage tests require `examples/stages06-07/requirements.txt`; without it those checks are explicitly skipped. Inspect the test assertions, make one deliberate regression and confirm the matching check fails before restoring it.

## Deliverable

Use `specialists_with_fallback`, not merely the original partial-result envelope.
After transient exhaustion, a timeout or a permanent schema error, inspect the
distinct `draft_manual_review` fallback, its failed role/reason and
`application-failure-policy-v1` attribution. Healthy facts remain unchanged;
`unresolved` remains populated. Verify `facts_recovered=False` and `sent=False`.
This is a real alternative recovery action, not a fabricated replacement policy.
No provider run is needed to prove these enforced local failure boundaries.

Submit your change, actual terminal output, the source of each reported fact and one limitation. Separate local deterministic events from SDK object behavior and actual model observations. Any lesson claim about model delegation, streamed model content or hosted traces remains pending an authorized live run. See `examples/stages06-07/README.md` for opt-in instructions.
