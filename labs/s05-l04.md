# s05-l04: Context Engineering for Personal Knowledge Agents

Organize instructions, professional data, conversation state and tool results within the available context.

## Practical

Construct contexts at 250 and 10 character budgets.

Read `projects/01-digital-twin/workflow.py` and its project README. Use synthetic fixtures only. Run `python3 -m unittest discover -s tests -p test_stages_05_08.py -v` and the project CLI. Distinguish offline observations from live SDK/browser/deployment work; do not claim unexecuted outcomes.

## Acceptance

A viable budget retains whole approved sections; too-small mandatory instruction/question budget raises ValueError rather than truncating authority.

Record the actual command, observed output and any unmet named application requirement.

Show whole-item omissions and stable citation IDs. Inject a known tokenizer counter only when available and label its units; do not compare character counts directly to provider token limits.
