# s18-l09: Approve, Edit or Reject Agent Actions

Build decision controls that let users approve, modify or cancel a proposed action.

## Practical exercise

Approve one proposal, reject another, and edit a third; try the old digest after editing before sending a fresh approval.

## Acceptance and reference reasoning

Edit is a new proposal, not immediate permission to execute changed text. The graph validates the edited payload, creates its changed digest and interrupts again. The old approval is stale; only a fresh exact approval of the replacement can dispatch it. Reject dispatches nothing and preserves the decision history.
