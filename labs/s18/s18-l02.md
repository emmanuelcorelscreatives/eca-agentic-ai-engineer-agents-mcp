# s18-l02: Persist Agent State with SQLite

Save checkpoints in SQLite so agent state survives application restarts.

## Actual repository implementation

Read `examples/s18/durable_sessions.py` → `Sessions.load`. Run from repository root:

```sh
python -m unittest discover -s tests -p test_stages16_19.py -v
```

## Exercise

Write a checkpoint in one Python process, reopen in another and append a second turn.

## Acceptance and evidence

SQLite commits checkpoint rows plus head updates transactionally and closes connections. The actual unittest launches a fresh subprocess, proving persistence rather than a process-local dictionary.
