# s07-l10: Trace a Complete Multi-Agent Run

Objective: Follow an execution from initial request through delegation, tools, handoffs and final synthesis.

Use Python 3.10 or newer. All data in `data/s06-catalogue.json` and `data/s07-support-cases.json` is synthetic Academy teaching data. No customer records or live provider results are included.

## Work

Reconstruct one run from root through delegation, tool events, synthesis and terminal state. Verify every parent exists and all run IDs agree. Attempt to log a secret in user_text and confirm the allowlist rejects it.

Implementation to inspect: `examples/stages06-07/workflows.py` and `examples/stages06-07/sdk_adapter.py`, symbols `LocalTrace / specialists`.

## Run and check

From the repository root:

```sh
python3 -m unittest discover -s tests -p test_stages_06_07.py -v
python3 examples/stages06-07/workflows.py --stage 7
```

Relevant acceptance check: `test_trace_correlation_privacy_and_complete_run`. Optional actual SDK construction/storage tests require `examples/stages06-07/requirements.txt`; without it those checks are explicitly skipped. Inspect the test assertions, make one deliberate regression and confirm the matching check fails before restoring it.

## Deliverable

Use `connected_application_run` for one complete, explicitly deterministic lineage
with delegation, tool results, a handoff and final synthesis under the receiving
owner. For a separately authorized actual SDK run, use `--mode complete` and a new
`--trace-file`. Inspect `complete_lineage_observed`; it must remain false if the
model skipped either specialist, shipping or the handoff. Bind every actual span
to the same root SDK trace and retain its parent linkage. Never combine two
unrelated runs or relabel the local application trace as a hosted SDK capture.

Submit your change, actual terminal output, the source of each reported fact and one limitation. Separate local deterministic events from SDK object behavior and actual model observations. Any lesson claim about model delegation, streamed model content or hosted traces remains pending an authorized live run. See `examples/stages06-07/README.md` for opt-in instructions.
