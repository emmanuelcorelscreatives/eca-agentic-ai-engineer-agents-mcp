# s23-l11: Build Reusable Agent Components

Package instructions, tools, schemas and policies into components that can support multiple projects.

## Exercise

Reuse PolicyService, RequestContext, strict validators and policy_lookup. Keep lifecycle cleanup in the adapter rather than global state.

Use the actual source files below; no model or SDK execution is implied by file existence.

- `examples/s23_workflow.py`
- `examples/s23_framework_agents.py`
- `examples/s23_ecosystem.md`
- `data/s23_workflow.json`
- `data/s22_support.json`

Offline verification from repository root:

```sh
python3 -m unittest discover -s tests -p test_stages21_24.py -v
```

## Acceptance requirements

- Both examples import the same reusable components and execute independently.
- Contract tests detect breaking schema or instruction-bundle changes.
- Different sessions/configurations do not leak mutable state or tool privileges across agent instances.
- The published package examples include install, run, exercise and solution instructions.
