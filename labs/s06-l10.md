# s06-l10: Inspect and Debug Agent Traces

Objective: Use traces to understand model calls, tool use, handoffs, failures, latency and token consumption.

Use Python 3.10 or newer. All data in `data/s06-catalogue.json` and `data/s07-support-cases.json` is synthetic Academy teaching data. No customer records or live provider results are included.

## Work

Run an invalid course ID and a valid ID into separate local traces. Find failed tool status and terminal state, then explain how a genuine authorized SDK trace would differ. Seed an unapproved private trace field and confirm rejection.

Implementation to inspect: `examples/stages06-07/workflows.py` and `examples/stages06-07/sdk_adapter.py`, symbols `LocalTrace / catalogue_run`.

## Run and check

From the repository root:

```sh
python3 -m unittest discover -s tests -p test_stages_06_07.py -v
python3 examples/stages06-07/workflows.py --stage 6
```

Relevant acceptance check: `test_trace_correlation_privacy_and_complete_run`. Optional actual SDK construction/storage tests require `examples/stages06-07/requirements.txt`; without it those checks are explicitly skipped. Inspect the test assertions, make one deliberate regression and confirm the matching check fails before restoring it.

## Deliverable

Inspect `sdk_observation.py` and the README's `--trace-file` route. Trace a real
SDK run only after its separate budget authorization. Save actual span IDs,
parent links, model/tool/handoff events, per-call monotonic durations and available
usage. A missing counter is unknown, not zero. Local SDK span export proves local
SDK instrumentation; it does not prove hosted upload. The provider-free test
creates genuine nested SDK function spans and checks redaction without making
model calls. Model/hosted observations and screenshots remain separately pending.

Submit your change, actual terminal output, the source of each reported fact and one limitation. Separate local deterministic events from SDK object behavior and actual model observations. Any lesson claim about model delegation, streamed model content or hosted traces remains pending an authorized live run. See `examples/stages06-07/README.md` for opt-in instructions.
