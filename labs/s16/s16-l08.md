## Practical exercise

Inspect model and tool middleware. Send an oversized input, unsupported page and valid request; compare outcomes and redacted timing records.

## Acceptance and reference reasoning

The model policy bounds text input and overrides request-local context with recent complete turns and explicit Academy instructions. Tool policy checks tool name and exact arguments before handler execution. Trace records contain random trace/span/parent correlation IDs, outcome and elapsed time rather than prompts, arguments, secrets or raw exception text. Logging is evidence only after actual execution.
