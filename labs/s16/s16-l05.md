# s16-l05: Bind Tools to Language Models

Make tool definitions available to a model and inspect generated tool-call requests.

## Coherent course case and actual source

Read `examples/s16/native_features.py` → `bind_and_inspect`. These are source references, not evidence that the new feature has passed runtime verification.

## Practical exercise

Bind academy_page to a configured model and inspect the returned call ID, name, arguments and invalid_tool_calls before dispatch.

## Acceptance and reference reasoning

bind_tools exposes the real tool schema but does not run a requested function. bind_and_inspect returns native proposal records and the schema; application execution remains a separate controlled boundary. An absent request must remain absent.

## Verify your result
