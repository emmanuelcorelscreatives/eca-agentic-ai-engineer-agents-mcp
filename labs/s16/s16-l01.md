## Practical exercise

Classify six requirements: one model answer, a typed page tool, explicit graph routing, trace inspection, resumable application state and delegated research. Explain when a plain model invocation is sufficient.

## Acceptance and reference reasoning

LangChain supplies model/tool integration and create_agent; LangGraph supplies graph execution and persistence; LangSmith supplies observability; Deep Agents supplies the planning/files/skills/delegation harness. These are cooperating layers, not four interchangeable model providers. No function named ecosystem-map exists or is required.
