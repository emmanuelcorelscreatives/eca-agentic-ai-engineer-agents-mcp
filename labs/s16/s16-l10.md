# s16-l10: Trace and Inspect Agent Runs

Examine model calls, tool execution, timing, failures and final outputs through traces.

## Coherent course case and actual source

Read `examples/s16/native_features.py` → `make_agent`. These are source references, not evidence that the new feature has passed runtime verification.

## Practical exercise

Inspect actual model/tool timings, successful final output and one controlled middleware/tool failure. Explain what is retained and what is deliberately redacted.

## Acceptance and reference reasoning

Native middleware surrounds actual SDK execution and records trace/span/parent correlation IDs, kind, status and elapsed_seconds. A useful trace distinguishes model and tool activity, errors and the associated final result. Local real execution tracing can meet this lesson; fixture_agent scripted events alone cannot prove native execution.
