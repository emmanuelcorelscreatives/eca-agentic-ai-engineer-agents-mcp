## Practical exercise

## Acceptance and reference reasoning

make_agent defaults to process-local InMemorySaver. recent_turns keeps complete user-led turns so AI/tool pairs stay together; model-local context trimming does not itself rewrite stored state. prune_thread explicitly replaces older checkpoint messages between completed serialized invocations. This is turn-count management, not a token-budget or restart-survival guarantee.
