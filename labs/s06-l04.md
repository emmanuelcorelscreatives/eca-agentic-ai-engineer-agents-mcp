# s06-l04: Build Your First SDK Agent

Objective: Define an agent, execute it with a runner and inspect the resulting response object.

Use Python 3.10 or newer. All data in `data/s06-catalogue.json` and `data/s07-support-cases.json` is synthetic Academy teaching data. No customer records or live provider results are included.

## Work

Run ECA-101 and ECA-999 offline. Construct the actual SDK agent without sending requests. For the optional live exercise use an explicitly chosen available model and require catalogue_lookup facts in its output.

Implementation to inspect: `examples/stages06-07/workflows.py` and `examples/stages06-07/sdk_adapter.py`, symbols `make_agents / catalogue_run`.

## Run and check

From the repository root:

```sh
python3 -m unittest discover -s tests -p test_stages_06_07.py -v
python3 examples/stages06-07/workflows.py --stage 6
```

Relevant acceptance check: `test_catalogue_known_unknown_invalid`. Optional actual SDK construction/storage tests require `examples/stages06-07/requirements.txt`; without it those checks are explicitly skipped. Inspect the test assertions, make one deliberate regression and confirm the matching check fails before restoring it.

## Deliverable

Submit your change, actual terminal output, the source of each reported fact and one limitation. Separate local deterministic events from SDK object behavior and actual model observations. Any lesson claim about model delegation, streamed model content or hosted traces remains pending an authorized live run. See `examples/stages06-07/README.md` for opt-in instructions.
