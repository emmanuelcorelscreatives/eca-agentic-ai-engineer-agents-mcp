## Acceptance requirements

- The sensitive sandbox tool cannot run while approval is pending or denied.
- Approval binds request ID, tool name, argument digest and current workflow state.
- Only an actual human UI/CLI decision is labeled human approval; agents cannot self-approve.
- Duplicate, stale and expired decisions cannot execute the action twice.
